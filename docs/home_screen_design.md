# 大学受験英単語アプリ ホーム画面UI設計書

対象範囲: 起動〜ホーム画面まわりのUIロジック（フラッシュカード自体の学習ロジックは実装済みのため対象外）

---

## 0. 前提となるデータモデル（UIロジックの前提）

このアプリの単語帳は「実体が別々のデータ」ではなく、**共通のWordプールに対するフィルタビュー**として扱う。

```
Word
 ├─ word_id
 ├─ required_for_common_test: bool
 └─ required_for_schools: [school_id, ...]   // 0件以上

UserWordState（Word単位で1つだけ。単語帳をまたいで共有）
 ├─ user_id, word_id
 ├─ mastery / stability / difficulty
 ├─ due_date
 └─ last_rating (Again/Hard/Good/Easy)
```

- ある単語が「共通テストにも志望校にも必要」な場合、**学習履歴は1つ**。どちらのデッキで先に学習しても、もう一方では新規カードとして再出題されない。
- 単語帳は下記の**2つで固定**。
  1. **共通テスト単語帳**（無料、全ユーザー共通の1デッキ）
  2. **志望校単語帳**（課金、登録した志望校の必要語彙を統合した1デッキ。複数校登録時も単語帳は増えず、内部で重複排除・統合される）
- 志望校別の進捗%は、単語帳を分けずに `required_for_schools` にその学校IDを含む単語群に対してmasteryを集計することで算出する（データは1つ、集計だけ学校別に出す）。

## 1. 画面構成（情報アーキテクチャ）

```
起動
 └─ 初回のみ: オンボーディング
      └─ 完了後 → ホーム
 └─ 2回目以降 → ホーム（ボトムナビ）
      ├─ ホーム（デフォルトタブ）
      ├─ ライブラリ
      ├─ 分析
      └─ 設定（既習教材/志望校/試験日の再編集はここから）
```

## 2. オンボーディングフロー（初回起動のみ）

| Step | 画面 | 内容 |
|---|---|---|
| 1 | コンセプト説明 | 1〜2枚。「単語帳を1冊ずつ潰すのではなく、志望校に必要な差分だけ埋める」ことを伝える。スキップ可 |
| 2 | 操作チュートリアル | Again/Hard/Good/Easyの意味と操作方法を、実データではない練習カード1〜2問で体験させる。スキップ可 |
| 3 | 学年選択 | 高校1年生 / 高校2年生 / 高校3年生 / 既卒（浪人）の4択。**無料ユーザーも含め必須**（スキップ不可）。「高3・既卒」かどうかだけを判定に使う（詳細は2.1章）。後で設定画面から変更可能 |
| 4 | 既習教材選択 | 複数選択可（シス単/LEAP/ターゲット1900/鉄壁/速単上級編など）。「後から設定で変更可能」の注記を出す。スキップ可 |
| 5 | 志望校選択 | 検索付き追加UI、複数校登録可。**この画面で未課金の場合は「志望校機能は課金が必要」の案内を表示しつつ、選択自体は許可し、完了時にペイウォールへ誘導**（詳細は6章）。スキップ可 |
| 6 | 試験日設定 | **志望校を登録した場合のみユーザーに入力を求める**。学校・学部ごとの正確な入試日程をユーザーが直接入力する（自動推測はしない。学部により日程が異なり、かつ年度によって変動するため）。志望校未登録（無料）ユーザーには、この画面自体を表示しない |
| 7 | サマリー画面 | 「あなたに必要な語彙: ○語 / 既習候補: ○語 / 追加学習: ○語」を表示 → 「学習をはじめる」ボタンでホームへ遷移 |

**注記**: Step4〜6はスキップ可能にする。スキップした場合はホーム画面が空状態（7章参照）で起動する。Step3（学年）のみスキップ不可とする（設定画面から後で変更可能）。

### 2.1 共通テストカウントダウンの表示条件

未確定の日付を推測して表示することはしない。表示できるのは**公式に確定している日程のみ**とする。

- **対象は「高校3年生」「既卒（浪人）」のみ**。この2つの学年は、直近の共通テストを受験する対象であり、実施時期には大学入試センターが公式に確定・公表した日程が存在するため、その日付をそのまま採用してカウントダウン表示する
- **「高校1年生」「高校2年生」は対象外**。自分が受験する回の共通テストの日程は、その時点でまだ公式発表されていない可能性があるため、**年度をずらして推測することはしない**。この場合、ヘッダーには日付カウントダウンを表示せず、進捗%のみを表示する（3.1章参照）
- 実施日データは、大学入試センターが公表した最新の確定日をアプリ内のデータとして保持し、更新する運用とする（次年度分は発表され次第、開発側で追加）
- 高1・高2ユーザーが学年を更新して高3になったタイミング、または既に日程が公式発表されている場合は、その時点で自動的にカウントダウン表示を開始する

## 3. ホーム画面

### 3.1 レイアウト構成（上から順）

1. **ヘッダー**: 試験日カウントダウン + 全体進捗%のプログレスバー
   - 志望校登録済み（課金）: 「慶應理工まで あと161日」など、最も近い志望校の試験日を優先表示
   - 志望校未登録（無料）かつ学年が「高3・既卒」: 「共通テストまで あと◯日」を確定日程から表示（2.1章）
   - 志望校未登録（無料）かつ学年が「高1・高2」: 日付カウントダウンは表示せず、進捗%のみを表示（未確定の日付を推測表示しないため）
2. **今日の学習カード（2枚、横並び or 縦積み）**
   - カードA: 「共通テスト」新規○語・復習○語 → 「開始」ボタン
   - カードB: 「志望校対策」新規○語・復習○語 → 「開始」ボタン（未課金時はロックアイコン付き、タップでペイウォールへ）
   - **合算表示はしない**。ユーザーが「共通テストだけ」「志望校だけ」を選んで学習できることを優先する
3. **志望校別進捗**（複数校ある場合、横スクロールカード or リスト）
   - 例: 慶應理工 72% / 早稲田理工 68% / 理科大 81%
   - 未課金時はこのセクション自体を非表示、または「ロック中」のプレースホルダーカード1枚のみ表示
4. **週間学習量**（曜日別の棒グラフ or ヒートマップ、直近7日）
5. **弱点語彙ショートカット**
   - Again率が高い語 or 想起率が低い語を3〜5件表示
   - タップで即座にその語だけの復習セッションを開始できる
6. **ライブラリへの導線**（検索バー、タップでライブラリタブへ遷移）

### 3.2 「今日の学習」開始ボタンを押した後の遷移

- カードA（共通テスト）→ 共通テスト単語帳のみをフィルタしたレビューキュー（新規→復習の順、または既存のSRSロジックに従う）でフラッシュカード画面へ
- カードB（志望校対策）→ 志望校単語帳のみをフィルタしたレビューキューでフラッシュカード画面へ
- 弱点語彙ショートカット → 該当語のみのアドホックなレビューキューでフラッシュカード画面へ（この場合、通常のSRS due_dateに関わらず強制的に復習対象に含める）

## 4. ライブラリ画面

- 検索バー（英単語 or 日本語訳で検索）
- フィルタ: 志望校別 / 共通テストのみ / 習熟度別（未学習・学習中・定着済み） / 品詞別
- 一覧はカード形式ではなくリスト形式（lemma + 簡易訳 + 習熟度アイコン）
- タップで単語詳細画面（全語義・語法・Word Family・例文などを表示。SRS状態も閲覧可）
- **辞書的な使い方を想定**: 学習セッション外でも単語を引けることが目的。ここからSRSキューに手動追加する操作は不要（自動判定に任せる）

---

## 5. 分析画面

- 全体語彙進捗（共通テスト/志望校それぞれ、または統合、円グラフ or バー）
- 志望校別の進捗内訳（複数校ある場合は横並び比較）
- 週間/月間の学習量推移（折れ線 or 棒グラフ）
- Again率・想起率の推移（定着傾向を見せる）
- 弱点語彙リスト（ホームより詳細な一覧、語義単位の弱点も表示: 例「observeの『遵守する』の意味が弱い」）
- 試験日ベースの進捗予測: 「このペースなら試験日までに◯%完了見込み」。遅延している場合は警告表示
- **試験日未設定の場合**: 逆算ベースの予測セクションは非表示にし、代わりに「試験日を設定すると学習計画が自動生成されます」のCTAを表示

---

## 6. 課金（ペイウォール）ロジック

- 無料ユーザーが触れられる範囲: 共通テスト単語帳のみ（学習・進捗・分析すべて）
- 志望校関連の要素（志望校単語帳、志望校別進捗、志望校ベースの試験日逆算）は全てロック
- ロックされた要素をタップした際の挙動: その場でペイウォール画面（志望校登録のメリット説明 + 課金導線）を表示。強制的な全画面割込みではなく、モーダル or 専用画面遷移で戻れるようにする
- オンボーディング中に志望校を選択した未課金ユーザーは、選択情報自体は保持しておき（課金後にそのまま反映されるように）、サマリー画面で課金導線を出す

## 7. エッジケース・空状態

| 状態 | ホーム画面の挙動 |
|---|---|
| 既習教材未登録 | 既習候補0件として扱う。「既習教材を登録すると学習効率が上がります」のヒントを表示（必須にはしない） |
| 志望校未登録（無料）かつ学年が「高3・既卒」 | ヘッダーは確定済みの共通テスト日程で「あと◯日」を表示（2.1章）。カードBはロック状態。共通テスト単語帳のみで機能する |
| 志望校未登録（無料）かつ学年が「高1・高2」 | ヘッダーは進捗%のみ表示（カウントダウンなし）。カードBはロック状態。共通テスト単語帳のみで機能する |
| 学年が未設定のまま利用が続いた場合 | ヘッダーは「学年を設定してください」のCTAを表示（Step3をスキップ不可にしているため通常発生しないが、設定画面で学年をクリアした場合のフォールバックとして定義） |
| 志望校登録済みだが試験日未入力 | カウントダウン非表示。進捗%と新規/復習件数は通常表示（試験日ベースの動的配分だけ止める） |
| 全てのタスク完了（今日の新規・復習が0件） | 「今日の分は完了しました」の状態表示。弱点語彙の任意復習は引き続き可能 |
