# 大学受験英単語アプリ バックエンド解析・アルゴリズム構築指示書

## 1. プロジェクトの目的と概要
あなたは、大学受験生向けの画期的な英単語アプリを構築するバックエンドエンジニアおよびデータサイエンティストです。
「プロジェクト概要.txt」を読み込み、本アプリのコアコンセプトである「既習教材の引き継ぎ」と「志望校に必要な語彙の差分抽出」を実現するためのデータパイプラインを構築してください。

## 2. 参照する入力データ（教師データ）
以下のファイルを読み込み、単語の難易度を測るための「基準データ」としてのみ使用してください。
※重要：著作権法に準拠するため、これらのデータをアプリのフロントエンドにそのまま出力・再現する機能は絶対に実装しないでください。あくまでバックエンドでの難易度計算（情報解析）のための特徴量として扱います。

* システム英単語［シス単］（5訂版）一覧.pdf (1〜2027語)
* ターゲット1900 6訂版　一覧　新.pdf (1〜1900語)

## 3. 単語難易度（0.0〜10.0）算出アルゴリズムの要件
各単語（Lemma）に対し、以下のロジックで0.0から10.0の連続値となる難易度レベルを自動算出するスクリプトを実装してください。

### Step 1: 基礎難易度ベースラインの算出
市販の基礎単語帳における「掲載位置（インデックス）」をパーセンタイル化し、平均値を取得します。後ろに掲載されている単語ほどスコアが高くなります。

* 計算式（プレーンテキスト）:
  Base_Score(word) = (各単語帳でのインデックス番号 / その単語帳の総単語数) の平均値
* 複数の単語帳に重複して掲載されている単語は、基礎重要度が高いとみなすため、重複割引係数（例: 0.9）を掛けて難易度を下げてください。

### Step 2: 入試特異性ブーストの加算
過去問コーパスからTF-IDFを計算し、特定の大学・学部で特異的に出現する単語の難易度を引き上げます。

* 計算式（プレーンテキスト）:
  Boost_Score(word) = 過去問コーパスにおける各大学の TF-IDF の最大値 * 重み付け係数

### Step 3: 正規化（0.0 〜 10.0）
外れ値（超低頻度のノイズ単語など）を除外した上で、以下の式で0.0から10.0にマッピングしてください。

* 計算式（プレーンテキスト）:
  Raw_Score = Base_Score(word) + Boost_Score(word)
  Level = 10.0 * (Raw_Score - 最小値) / (最大値 - 最小値)

## 4. データ構造と例外処理の要件
* **WordとUserWordStateの分離:** 単語のマスターデータ（Word）と、ユーザーごとの習熟度データ（UserWordState）は完全に分離したデータベーススキーマを設計してください。
* **フレーズ・句動詞の独立:** "look" のような基礎語であっても、"look forward to" などの句動詞は単語本体とは分離し、独立した学習対象（別のレコード）としてスコアを計算してください。
* **Word Familyの独立:** "history" と "historical" などは関連付けつつも、カードとしては独立させ、別々に難易度を計算してください。
